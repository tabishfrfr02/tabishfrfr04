01 // GAME UI

UI GAME ANIMATION AD

A full mobile-game ad built entirely from static UI exports — main menu, gold shop, gun selection, daily rewards, mode select. Every screen was animated to transition like a live app: buttons press, panels slide, currency counts up, rarity glows pulse. The goal was to make flat design assets feel like an actual playable interface.
